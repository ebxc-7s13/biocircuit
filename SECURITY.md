# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: **Security → Report a vulnerability** on https://github.com/ebxc-7s13/biocircuit. Do not open public issues for security problems, and do not include other people's personal data in reports.

This is a single-maintainer preview project with no guaranteed response time.

## Scope

- The static app at https://ebxc-7s13.github.io/biocircuit/
- The SQL migrations, RLS policies and Edge Functions in this repository

Testing must stay on your own accounts. Do not use automated scanning that degrades service, and do not try to access other users' data.

Controls, tested negative cases and known gaps are documented in [docs/SECURITY.md](docs/SECURITY.md).
